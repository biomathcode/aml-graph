# Current release scope

- [x] PostgreSQL and Drizzle persistence
- [x] Redis live updates, rate limiting and expiring upload tickets
- [x] Tenant-scoped access to application data and documents
- [x] Local, AWS S3, Google Cloud Storage and Cloudflare R2 document storage adapters
- [x] Public PDF/image collection with expiring secret links
- [x] Analytics, branding, blocklist and manual review
- [x] Questionnaires, publication and responses
- [x] API keys, REST endpoints, signed webhook delivery and optional SMTP
- [x] Self-hosted Docker Compose package and custom-domain instructions
- [ ] Configure and verify the user's actual cloud bucket credentials
- [ ] Deploy to a remote server once a target is provided
- [ ] Import live Convex data once an export and ownership mapping are provided
- Deferred by user: RabbitMQ document workers, OCR and automatic document processing
